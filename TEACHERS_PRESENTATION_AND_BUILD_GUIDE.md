### Step 1: Setting Up Your Environment
1. **Install Prerequisites**:
   - Install **Node.js** (v20 or v22 LTS) from [nodejs.org](https://nodejs.org).
   - Install **Visual Studio Code** from [code.visualstudio.com](https://code.visualstudio.com).
   - Recommended VS Code Extensions:
     - *Tailwind CSS IntelliSense*
     - *ESLint*
     - *Prettier - Code Formatter*
2. **Open VS Code and Launch Terminal**:
   - Open VS Code, select **File > Open Folder** and create your project folder `dips-portal`.
   - Press `` Ctrl + ` `` (or `Cmd + \`` on Mac) to open the integrated terminal.

### Step 5: Full-Stack Server Integration (`server.ts`)
The server serves both the **REST API** and the **Vite frontend**:

```typescript
import express from 'express';
import path from 'path';
import fs from 'fs';
import { createServer as createViteServer } from 'vite';
import { resourceRouter } from './server/routes/resourceRoutes.js';
import { branchRouter } from './server/routes/branchRoutes.js';
import { authRouter } from './server/routes/authRoutes.js';

async function startServer() {
  const app = express();
  app.use(express.json({ limit: '50mb' }));

  // Static uploads directory
  const uploadsDir = path.join(process.cwd(), 'public', 'uploads');
  if (!fs.existsSync(uploadsDir)) fs.mkdirSync(uploadsDir, { recursive: true });
  app.use('/uploads', express.static(uploadsDir));

  // Mount API routes
  app.use('/api/auth', authRouter);
  app.use('/api/branches', branchRouter);
  app.use('/api/resources', resourceRouter);

  // In development, connect Vite middleware for instant hot reloading
  if (process.env.NODE_ENV !== 'production') {
    const vite = await createViteServer({
      server: { middlewareMode: true },
      appType: 'spa',
    });
    app.use(vite.middlewares);
  } else {
    // In production, serve static built files
    app.use(express.static(path.join(process.cwd(), 'dist')));
    app.get('*', (req, res) => {
      res.sendFile(path.join(process.cwd(), 'dist', 'index.html'));
    });
  }

  app.listen(3000, () => console.log('DIPS Portal running at http://localhost:3000'));
}
startServer();
```

### Step 7: Deploying to Production (Render)
1. Commit your code to GitHub:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of DIPS Centralized Portal"
   git branch -M main
   git remote add origin https://github.com/your-username/dips-portal.git
   git push -u origin main
   ```
2. Link your GitHub repository in [Render.com](https://render.com).
3. Set the build command to:
   ```bash
   npm install && npm run build
   ```
4. Set the start command to:
   ```bash
   npm start
   ```
5. Whenever you need to refresh your live production site:
   - Click **Manual Deploy** ➔ **Clear build cache & deploy** on the Render Dashboard.
